# MTA-Stories

**SAxVCxLC Stories** — RPG/RP-сервер для Multi Theft Auto: San Andreas, объединяющий карты VC и LC с SA. Готовая к запуску сборка сервера под Windows: ресурс гейммода `228`, интерфейс (`Interface`), работы (`job`), чат, погода и прочее — всё в одном репозитории.

## Быстрый старт

1. Скачайте/клонируйте репозиторий.
2. Откройте `mods/deathmatch/resources/228/script.lua` и в **первой строке** укажите IP вашего сервера:

   ```lua
   local SERVER_IP = "Ваш.IP.адрес.здесь"
   ```

3. Запустите `MTA Server.exe` в корне репозитория.
4. Подключайтесь из MTA:SA по этому IP.

> Список ресурсов, запускаемых при старте сервера, находится в конце `mods/deathmatch/mtaserver.conf`.

## Что внутри

| Путь | Назначение |
|---|---|
| `MTA Server.exe` | Windows-сервер MTA:SA, готов к запуску |
| `mods/deathmatch/resources/228/` | Основной гейммод: экономика, фракции, работы, инфраструктура |
| `mods/deathmatch/resources/Interface/` | UI, HUD, GPS-маркеры, Global Chat |
| `mods/deathmatch/resources/job/` | Работы: такси, дальнобойщик, пиццерий |
| `mods/deathmatch/resources/vehicle_node/` | Трафик и ноды транспорта |
| `mods/deathmatch/mtaserver.conf` | Конфиг сервера и список стартовых ресурсов |
| `mods/deathmatch/databases/` | SQLite-данные (создаются при работе сервера) |

## Особенности гейммода

- **Работы**: такси с механикой оригинальной GTA SA (терпение пассажира, таксометр $0.5/метр, чаевые за быструю доставку), дальнобойщик, развоз пиццы.
- **Тюнинг**: полное меню тюнинга автомобилей (двигатель, турбо, трансмиссия, подвеска, тормоза, шины) с сохранением handling.
- **Расследование преступлений**: механика оригинальной GTA SA (звёзды розыска, реакция полиции).
- **Global Chat**, интернет-радио, казино, уникальные прыжки, PS2-погода и многое другое.

## Содержимое репозитория

- Lua-ресурсы и конфиги сервера — можно свободно править.
- Runtime-данные (`databases/`, `logs/`, `resource-cache/`, `backups/`) — создаются сервером, в репозитории служат примером состояния.
- Модельные ассеты (`.dff`, `.txd`, `.col`) коммитятся напрямую, без Git LFS.
